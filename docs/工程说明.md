# 工程说明

## 状态约定

计划使用六维状态：

```text
[p, dp, theta1, dtheta1, theta2, dtheta2]
```

实际编程前需要通过 MuJoCo 的 joint 地址确认 `qpos`、`qvel` 的排列。

## 模块规划

1. `mujoco_interface`：模型加载、状态读取和控制输入；
2. `dynamics`：连续动力学和离散预测；
3. `linearize`：计算平衡点附近的 A、B 矩阵；
4. `lqr`：离散 Riccati 方程和局部反馈；
5. `lmpc`：基于线性模型的约束预测控制；
6. `ilqr`：无约束或软约束非线性摆起；
7. `nmpc`：带约束非线性预测控制；
8. `supervisor`：控制器模式切换；
9. `safety_filter`：输入限幅和异常保护。

## 模式切换

```text
大角度 → iLQR/NMPC
接近平衡 → LMPC
LMPC 失败 → LQR
状态异常 → 安全模式
```

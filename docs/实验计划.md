# 实验计划

## V0 模型验证

- MuJoCo 能加载 XML；
- 能读取三个关节；
- 确认角度正方向和竖直平衡点；
- 确认执行器输入方向。

## V1 线性化验证

- 得到 6×6 的 A 矩阵和 6×1 的 B 矩阵；
- 检查数值是否有限；
- 比较线性模型与 MuJoCo 的短时轨迹。

## V2 LQR 验证

- 小角度初始状态能够稳定；
- 输入不持续饱和；
- 调节 Q、R 后结果符合预期。

## V3 LMPC 验证

- 输入约束有效；
- QP 求解失败时可以切换到 LQR；
- 记录求解时间和约束违反情况。

## V4 iLQR/NMPC 验证

- 多个大角度初始状态能够接近平衡区域；
- 代价函数总体下降；
- 超时和不可行时能够安全退出。

## V5 整体验证

- 摆起控制能够交给 LMPC；
- LMPC 能够交给 LQR；
- 模式切换没有明显抖动；
- 随机初始状态下统计成功率。
